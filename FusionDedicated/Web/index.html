Activity

Connected players

Rank changes apply immediately, nobody has to reconnect. A rank is stored against the SteamID, so it still holds next time they join. Purge deletes everything a player has spawned without removing the player.

Current level

Map list

Loading a map sends everyone to it and clears the world, since entities belong to the level they spawned in. For a modded map, give its mod.io id, a player who does not have it asks the server which mod to fetch, and downloads it.

Add a map

Mod catalogue 0

The server owns no mods, so it cannot look a modded item up itself. When a player asks where one came from, the server forwards the question to whoever spawned it and remembers the answer, after which it can serve that mod to anyone, including people who join long after the original owner left.

Server picture

The browser draws a server's picture from the level's mod.io thumbnail, so setting a mod.io id on the current map is what gives this server a custom image. There is no way to point it at an arbitrary URL, the id is the hook.

World control

The server owns nothing and simulates nothing, it only remembers what exists so late joiners can be caught up. An entity whose owner left has no machine applying physics to it and hangs in place until it is culled.

Crash protection

A spawn flood costs this server almost nothing, it never simulates anything - but every client has to build each prop, which is what drops a whole lobby at once. These limits are sized for what clients survive. Early strikes only delete the offending props; a kick comes after repeated attempts.

The minimum rank each action needs. Clients hide the buttons they think you may not press, but the server checks again before acting, so these are enforced, not cosmetic.
